# Publishing

Build and run all tests on each platform. Inspect editor fixtures at minimum/default/large sizes, empty and populated response graphs, Static/Dynamic/Spectral controls and Freeze/Resume. Record measurement conditions and retain verification logs. Build the corresponding source archive from the same code used for the binaries. Verify installer names, architecture, product identifiers and SHA256 checksums.

Publish from the main branch of neurorasolutions/Aester-EQ. Mark builds as previews until the corresponding installation and host checks have been completed. Do not attach unsigned AAX development bundles as user installers. Do not infer listening outcomes from numerical tests alone.
