# Windows preview

Aester EQ is built as x64 VST3 and standalone. See [installation](INSTALLATION.md) and [building](BUILDING.md). Each pipeline run records its tests and installer output. A green build does not certify a DAW or an interactive install.

The installer is unsigned. Use the official Microsoft Visual C++ x64 Redistributable if required by the operating system. Do not replace system DLLs with unofficial downloads.
