# Changelog

## Aester EQ 1.3.0 — DropDownAcademy edition

- New product identity: DropDownAcademy as manufacturer, `com.dropdownacademy.aestereq` bundle identifier, `DdAc` manufacturer code.
- Editor header and in-app help now carry the DropDownAcademy name and website.
- Rebuilt macOS installer: DropDownAcademy welcome and read-me pages, new text logo, refreshed distribution title.
- Rebuilt Windows installer: new install path, Start menu group, publisher and uninstall registry entries.
- Added Italian and English user manuals, included in both installers and in the macOS disk image.
- Processing, parameters and state schema are unchanged from 1.2.0. Presets created with 1.2.0 load unchanged.

## Aester EQ 1.2.0 — macOS preview

- Compact resizable Focus UI with a floating selected-band panel and fluorescent yellow highlights.
- Q-linked Solo monitoring with smooth transitions and editor-close reset.
- Rotary Balance, Mix and Output controls; global balance remains active at 0% Mix.
- Automatic Mid/Side output panel with separate component gain and polarity.
- State schema 8 preserves existing parameter IDs and defaults missing Mid/Side controls safely.
- macOS processor suites and installed AU validation passed; the rebuilt macOS ARM64 DMG includes AU, standalone and matching source.

## Aester EQ 1.1.0 — development preview

- Wide response workspace above a six-card band strip, with four pages for 24 band slots.
- Per-band frequency, gain and Q numeric editing, selection and enable switches.
- Persistent right-hand output rail with L/R peak meters, output level, balance, Mix and phase settings.
- Colored response overlays show each active band alongside the total wet response.
- Static, Dynamic and Spectral processing, external key input, latency-aligned Mix and spectrum Freeze.
- Standalone public product repository with source, third-party notices and single-product technical measurements.
